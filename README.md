# UAP Archive

A free, offline-capable UAP/UFO research terminal. 344 built-in cases, 
NUFORC analytics, mapping, FOIA search launcher. Runs entirely in your 
browser — no accounts, no tracking, nothing uploaded anywhere.

**🔭 Live tool:** https://caariunews.github.io/uap-archive/

## Features
- Interactive world map of 344 documented UAP/UFO cases across 49 countries
- Import your own CSVs (NUFORC formats auto-detected, tested to 80k+ rows)
- Analytics that adjust for reporting bias, population, and known stimulus events
- Side-by-side case comparison, nearby-location timelines, deep-dive views
- 32 FOIA / open-source search launchers
- Everything saved locally in your browser (IndexedDB) — no cloud

## Use
Just visit the live link, or download `index.html` and open it locally. 
Works offline after first load.
